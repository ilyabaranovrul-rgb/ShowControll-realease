# ShowControll

Show control for audio on Windows — cue list with GO, groups, fades, loops and slices, tempo grid,
QLab-style routing matrix and patches, multiple devices (ASIO / WASAPI), preview output.

## Download

**[⬇ Download ShowControll-stable-Setup.exe](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases/latest/download/ShowControll-stable-Setup.exe)** · [all versions](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases)

Run `ShowControll-stable-Setup.exe`. No administrator rights needed; ShowControll installs for your Windows user
and updates itself from this page (Help → Check for updates).

Windows may show "Windows protected your PC" (the program is not signed yet): click **More info → Run anyway**.

### Channels

- **Stable** — tested releases (default).
- **Beta** — new features first. Switch in ShowControll: **Help → Update channel**.
