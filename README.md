# ShowControll

Show control for audio and video on **Windows and macOS** — cue list with GO, groups, fades, loops and slices, tempo grid
and rehearsal markers, QLab-style routing matrix and patches, multiple devices, video and cameras, MIDI / OSC / network MIDI control.

## Download

| Device | Download | Install |
|---|---|---|
| 🪟 **Windows** 10 / 11 (64-bit) | **[⬇ ShowControll-Setup.exe](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases/latest/download/ShowControll-Setup.exe)** | Run it, choose the folder. Updates itself (Help → Check for updates). |
| 🍎 **macOS** 12 or later (Apple Silicon — M1 and newer) | **[⬇ ShowControll-Mac.dmg](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases/latest/download/ShowControll-Mac.dmg)** | Open it, drag ShowControll to Applications. |

[All versions and release notes](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases)

**Windows** may show "Windows protected your PC" (the program is not signed yet): click **More info → Run anyway**.
No administrator rights needed. The Velopack installer `ShowControll-stable-Setup.exe` (installs to your user folder) is in each release too.

**macOS** — first start: the app is not signed with a paid Apple account, so macOS cannot check the developer.
Open **System Settings → Privacy & Security** and click **Open Anyway** next to the message about ShowControll (once).
macOS asks for the microphone and camera the first time a cue uses them. New versions: download the new .dmg and drag it over the old app.

### Channels (Windows)

- **Stable** — tested releases (default).
- **Beta** — new features first. Switch in ShowControll: **Help → Update channel**.

# ShowControll (RU)

Управление шоу для звука и видео на **Windows и macOS**.

| Устройство | Скачать | Установка |
|---|---|---|
| 🪟 **Windows** 10 / 11 (64-бит) | **[⬇ ShowControll-Setup.exe](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases/latest/download/ShowControll-Setup.exe)** | Запустите, выберите папку. Обновляется сама (Help → Check for updates). |
| 🍎 **macOS** 12 и новее (Apple Silicon — M1 и новее) | **[⬇ ShowControll-Mac.dmg](https://github.com/ilyabaranovrul-rgb/ShowControll-realease/releases/latest/download/ShowControll-Mac.dmg)** | Откройте и перетащите ShowControll в «Программы». |

**Windows:** если появится «Windows защитила ваш компьютер» — **Подробнее → Выполнить в любом случае**. Права администратора не нужны.
Канал обновлений Stable / Beta — **Help → Update channel**.

**macOS, первый запуск:** программа не подписана платным аккаунтом Apple, поэтому macOS не может проверить разработчика.
Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** у сообщения о ShowControll (один раз).
Микрофон и камеру macOS попросит разрешить при первом использовании. Новая версия: скачайте новый .dmg и перетащите программу поверх старой.
